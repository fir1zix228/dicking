# Расписание дня → Календарь iPhone

Пишешь расписание обычным текстом — получаешь файл `.ics`, который iPhone
сам разложит по Календарю.

## Как пользоваться

1. Правишь `raspisanie.txt` под себя.
2. Запускаешь генератор:

   ```
   python3 make_ics.py raspisanie.txt -o raspisanie.ics
   ```

3. Закидываешь `raspisanie.ics` себе на телефон (почта, Telegram, AirDrop),
   открываешь — Календарь предложит добавить все события.

Полезные ключи:

| Ключ | Что делает |
|---|---|
| `-o файл.ics` | куда сохранить (по умолчанию `raspisanie.ics`) |
| `--start 2026-09-07` | с какой даты начать (по умолчанию сегодня) |
| `--weeks 12` | повторять 12 недель (по умолчанию `0` — бесконечно) |
| `--name "Учёба"` | название календаря |

## Формат строки

```
ДНИ  ЧЧ:ММ-ЧЧ:ММ  Название   [!минуты]
```

* **ДНИ** — `пн вт ср чт пт сб вс`; диапазон `пн-пт`; список `пн,ср,пт`;
  слова `ежедневно`, `будни`, `выходные`.
* **Время** — 24-часовое. Если конец меньше начала (`23:00-01:00`),
  событие уезжает на следующий день.
* **`!10`** в конце — напомнить за 10 минут до начала.
* Строки с `#` — комментарии, они игнорируются.

Пример:

```
будни     08:15-14:30  Школа            !20
пн,ср,пт  17:00-18:30  Тренировка       !30
ежедневно 23:00-23:30  Отбой            !10
```

## Автообновление (подписка на календарь)

Если не хочешь каждый раз пересылать файл — подпишись на него один раз,
и телефон будет сам подтягивать изменения из репозитория:

1. Возьми прямую ссылку на `raspisanie.ics`
   (на GitHub: кнопка **Raw**, адрес вида `raw.githubusercontent.com/...`).
2. На айфоне: **Настройки → Приложения → Календарь → Учётные записи →
   Добавить учётную запись → Другое → Добавить подписной календарь**,
   вставь ссылку.

Дальше меняешь `raspisanie.txt`, перегенерируешь `.ics`, пушишь в репозиторий —
телефон обновит расписание сам. Обновление не мгновенное: iOS проверяет
подписку по своему расписанию (можно поторопить, потянув календарь вниз).

Важно: подписной календарь **только для чтения** — редактировать эти события
на телефоне нельзя, только через файл.

## Как дополнять расписание потом

Расписание можно начинать с двух-трёх строк и дописывать по мере того,
как становится ясно расписание. Дописал строку → перегенерировал `.ics` →
импортировал заново.

Дубли не появятся: событие опознаётся **по названию**. Если у `Тренировка`
поменять время или дни, телефон обновит уже существующее событие. Поэтому:

* два разных занятия — два разных названия (`Английский` и `Математика`,
  а не два `Урок`);
* переименовал событие — для календаря это новое событие, старое
  придётся удалить на телефоне руками;
* удалил строку из файла — событие с телефона само не исчезнет,
  удаляй его в Календаре.

## Ограничения

* Время «плавающее» — без часового пояса. События показываются ровно в то
  время, что написано, в любом поясе. Для расписания дня это то, что нужно.
* Праздники и каникулы генератор не знает — такие дни правь руками или
  ограничивай период через `--weeks`.
